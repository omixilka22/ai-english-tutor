# Тижневе планування: проєкт поведінки, ще не реалізовано

Межі тижня: понеділок 00:00 - наступний понеділок 00:00, Europe/Kyiv.
Поточний тиждень містить і заплановані, і проведені заняття. Історія попередніх
тижнів доступна окремо. Проведення підтверджує лише викладач після завершення
запланованої тривалості уроку; факт проведення та аналіз - різні стани.

## Питання для узгодження

1. Запитувати щонеділі о 18:00 за Києвом? Без відповіді наступний тиждень
   залишається чернеткою; учням не надсилаються нагадування про чернетки.
2. За замовчуванням зміни стосуються лише обраного тижня, а постійний шаблон
   змінюється окремою дією?

## Запропонований процес

Постійний шаблон -> чернетка наступного тижня -> перегляд викладачем -> публікація.
Планування одразу для всіх учнів викладача; розклад доступний для редагування
і до неділі через меню. Нагадування у неділю - один запит за конкретний тиждень,
зі збереженням доставки та обмеженими повторами; після простою бота непогоджений
тиждень залишається доступним для ручного планування, без створення уроків заднім числом.

Три дії:
- Залишити розклад: попередній перегляд, підтвердження, публікація.
- Змінити окремі заняття: перенести/прибрати/додати урок у чернетці, потім підтвердити.
- Скласти заново: очистити лише чернетку вибраного тижня й заповнити її з нуля.

Поки план - чернетка, він невидимий учню й не створює сповіщень. Після публікації
видно лише реальні заняття. Подальші зміни опублікованих уроків користуються
наявними повідомленнями про перенесення/скасування. Застарілі кнопки та
подвійне підтвердження перевіряються за версією плану в транзакції.

## Перехід зі старої генерації

Не видаляти історію, проведені уроки, транскрипти або вручну додані/перенесені
заняття. Перед зміною видимості вже створених майбутніх звичайних уроків
показати викладачу перелік і заплановану дію. Припинення генератора 28 днів саме
по собі не прибере старі записи. Відміна/відкладення вже опублікованих занять
потребує окремого узгодженого переходу, щоб учні не отримали суперечливих нагадувань.

Потрібна спільна перевірка публікації тижня в генераторі, створенні/редагуванні
правил, API та сканері нагадувань. Заміна days=28 на days=7 не реалізує цей процес.
